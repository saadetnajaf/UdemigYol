# 🛍️ UdemigYol

Welcome to **UdemigYol** — a responsive e-commerce product listing web page built with HTML5 and CSS3. This project features a modern header with a search bar, navigation menu, shopping cart indicator, product categories, and product cards with ratings, prices, and interactive add-to-cart buttons.

---

## ⚙️ Features

✅ **Responsive Header**  
A flexible header featuring the UdemigYol logo, search bar, navigation links, and shopping cart icon.

✅ **Search Bar**  
A search input with a Bootstrap search icon for a familiar e-commerce experience.

✅ **Product Categories**  
A category navigation section with hover effects for a clean and interactive browsing experience.

✅ **Product Cards**  
Product cards displaying images, brand names, product descriptions, bestseller banners, star ratings, and prices.

✅ **Add to Cart Buttons**  
Interactive buttons featuring a smooth gradient hover animation.

✅ **Shopping Cart Indicator**  
A shopping cart icon with a badge displaying the current cart count.

✅ **CSS Grid Layout**  
A flexible product grid using `auto-fit` and `minmax()` to adapt the layout to different screen widths.

✅ **Responsive Design**  
A media query adjusts the header navigation for screens up to 900px wide.

✅ **Bootstrap Icons**  
Search, shopping cart, and star icons powered by Bootstrap Icons.

---

## 🛠 Technologies Used

- **HTML5** 🌐 — Semantic structure and page content
- **CSS3** 🎨 — Styling, layouts, transitions, and responsive design
- **CSS Grid** 📐 — Responsive product card layout
- **Flexbox** 📦 — Header, navigation, and category alignment
- **CSS Media Queries** 📱 — Responsive behavior for smaller screens
- **Bootstrap Icons** 🎯 — Search, cart, and rating icons
- **CSS Transitions & Gradients** ✨ — Animated add-to-cart button effects
